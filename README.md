Reading these on Pydroid3 / Android
The .md/.txt files need no special app — open in any text editor. They use light Markdown (# headers, **bold**, |table| pipes) that stays readable even unrendered.
Sourcing and honesty notes
Content is compiled largely verbatim from the source PDFs/docs where those documents are the authoritative record (e.g. the Formula Map, the Four Books). Light reorganization and connective text was added for readability, not to alter the technical content.
The Applications file's Addendum (§5–9) keeps a clear line between established chemistry/biology (which stands on its own evidence) and the SSDM overlay (a structural/diagnostic mapping, not a source of scientific evidence) — see §8 of that file for the explicit statement.
The Formulas file's closing summary table (§12) is flagged as the framework's own self-assessment, not independent verification — the α=1/137 and Weinberg-angle derivations are the claims most worth outside scrutiny.
Known gaps
DSER_66D_ARCHITECTURE.md (Google Drive) was located but not read in full or cross-checked against the 3-field (φ,χ,ρ) core — unresolved whether it's a genuine extension or an unrelated subsystem sharing the name.
The Drive DSER-USR2 folder nests below Actual_Science/MetatronCog.Inc; this compilation did not exhaustively enumerate every file at that depth.
Multiple near-duplicate copies of the same PDFs/docx exist across Drive folders (e.g. several copies of DSER_Canonical_Formula_Map.pdf). One canonical copy was used per document; duplicates were not diffed against each other for silent edits.
